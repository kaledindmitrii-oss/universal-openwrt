# WireGuard туннель — режимы

В LuCI блок **WireGuard туннель** содержит два режима, которые выбираются для каждого устройства отдельно.

## 1. Remote WireGuard

**Назначение:** безопасный удалённый доступ к роутеру и сети WireGuard без изменения обычного Интернет-маршрута устройства.

### Что проходит через туннель

Только сеть:

```text
10.66.66.0/24
```

Конфигурация клиента использует:

```text
AllowedIPs = 10.66.66.0/24
```

### Что не происходит

- весь Интернет не уходит через роутер;
- NAT для Internet не включается;
- default route клиента не изменяется;
- AWG/WARP не используется;
- Strategy Engine не участвует;
- Telegram Controller не участвует.

### Пример

Телефон находится в мобильной сети и подключается к роутеру по WireGuard.

```text
Телефон
  ├── 10.66.66.0/24 → WireGuard → роутер
  └── обычный Internet → мобильный оператор
```

Это режим удалённого доступа.

---

## 2. WireGuard VPN

**Назначение:** отправить IPv4 Internet выбранного устройства через домашний роутер.

Клиент получает:

```text
AllowedIPs = 0.0.0.0/0
```

На роутере для режима VPN автоматически используется отдельная политика:

```text
WireGuard zone → WAN
                  ↓
               NAT/MASQUERADE
```

### Пример

```text
Телефон
   ↓
WireGuard
   ↓
wg0 / uowrt_remote_wg
   ↓
WAN роутера
   ↓
Internet
```

### Важно

Режим является **IPv4 VPN**.

IPv6 пока намеренно не объявляется через туннель. Если у клиента есть независимое IPv6-подключение, оно может продолжить работать напрямую. Поэтому текущий режим нельзя считать полноценным IPv4+IPv6 kill-switch VPN.

DNS также не подменяется автоматически, если параметр `UOWRT_REMOTE_WG_CLIENT_DNS` не задан. Это сознательно отображается в диагностике.

## Белый IP

Для прямых входящих подключений WireGuard роутер должен быть доступен из Интернета.

LuCI проверяет:

1. WAN IPv4 роутера;
2. внешний IPv4, полученный через внешний сервис;
3. совпадение адресов;
4. private IPv4 диапазоны;
5. CGNAT `100.64.0.0/10`;
6. специальные IPv4 диапазоны.

### Белый IP подтверждён

Если WAN IPv4 совпадает с внешним IPv4 и не относится к непубличному диапазону:

```text
Белый IP: Да
```

Это необходимое условие для прямого входящего подключения.

### CGNAT / серый IP

Если роутер получает, например:

```text
100.64.x.x — 100.127.x.x
10.x.x.x
172.16.x.x — 172.31.x.x
192.168.x.x
```

или WAN IPv4 отличается от внешнего IPv4, LuCI показывает предупреждение.

Прямое входящее подключение WireGuard в такой конфигурации **не гарантируется**.

### Важное ограничение проверки

Совпадение публичного IPv4 не доказывает, что UDP/51820 разрешён провайдером или внешним firewall.

Поэтому итоговая формулировка интерфейса:

> **Корректная прямая работа входящего WireGuard гарантируется только при реально публичном IPv4 и доступном UDP-порту WireGuard.**

Если провайдер использует CGNAT, для гарантированной входящей доступности требуется отдельная архитектура — например внешний VPS/relay.
